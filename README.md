# 펜토미노 달력 퍼즐

초등 수학 수업용 퍼즐이에요. 1~31일 달력판에서 고른 날짜 한 칸만 남기고, 펜토미노 6개로 나머지 칸을 모두 채워요.

**바로 하기:** https://jeongyunjo924-code.github.io/pentomino-calendar/

- 전자칠판과 태블릿에서 터치로 해요. 밀면 옮기고, 터치하면 돌리고, 노란 버튼으로 뒤집어요.
- 오늘 날짜로 시작하고, 날짜 고르기와 무작위 버튼이 있어요.
- 힌트를 누르면 정답 조각 하나를 제자리에 놓아 줘요.
- 난이도 두 가지 모두 1~31일 모든 날짜에 답이 있어요.
- 파일은 `index.html` 하나뿐이고 설치가 필요 없어요.
